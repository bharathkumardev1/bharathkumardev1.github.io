Agentic Research Assistant

GitHub Live API

Answers questions over a set of research papers with a citation on every claim. Three LangGraph agents share one FAISS index: one retrieves, one drafts from those chunks only, and one grades the draft and sends a sharper query back if it's thin. The loop is capped so it always stops.

It runs as a FastAPI service with per-caller rate limits, timeouts, and Prometheus metrics, has 56 tests, and works offline with no API key.

The live demo is on a free host, so the first request can take up to a minute.
